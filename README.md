# CampusCanteen Backend

CampusCanteen Backend is a Python-based AI-powered backend system designed to enable advance food ordering for a Campus's Canteen. The system leverages a LangGraph-driven architecture and a Large Language Model to generate intelligent, context-aware responses for users interacting with any chat interface it may integrate with.

The backend is built with scalability in mind and can be extended to support multiple client platforms, including web applications, mobile apps, and messaging platforms such as WhatsApp, enabling a seamless pre-ordering experience across different interfaces.

## Tech Stack

- Python 3.12.3  
- FastAPI — API layer for frontend communication  
- MongoDB — primary database  

### Libraries & Frameworks

- LangGraph — workflow orchestration for conversational AI  
- LangChain — LLM integration and prompt management  
- Pydantic — data validation and schema enforcement  
- pymongo — MongoDB interaction  

## External APIs

- Gemini API (Gemini 2.5 Flash) for AI-generated conversational responses

## Key Responsibilities

- AI-driven conversational handling for food pre-ordering  
- Intent processing and workflow execution using LangGraph  
- Request and response validation using Pydantic models  
- Session and context management for user interactions  
- Data persistence and retrieval via MongoDB  
- Backend service exposure through FastAPI endpoints  

## Project Type

- Scalable backend system  
- Designed to integrate with web, mobile, and WhatsApp-based ordering platforms
